# WARI FIRE AI — inicio público

Prototipo público inicial para Wari Teams, NASA Space Apps Challenge 2026.

## Ejecutar localmente

```bash
py -3.13 -m pip install -r requirements.txt
py -3.13 -m streamlit run app.py
```

## Publicar

Subir `app.py`, `requirements.txt`, `README.md`, `assets/logo.png` y `.streamlit/config.toml` a GitHub y desplegar con Streamlit Community Cloud usando `app.py` como punto de entrada.

No subir claves secretas. Los datos del catálogo son descripciones introductorias, no mediciones.
